# Website · start here

The site is the **systems map** (branch `map-final` on `bryliejw/bryliejw.github.io`). Phases 1 to 4 of the map build are done; the content pass is done. `main` (v0) stays live until you approve the launch.

## What is ready

- **Preview:** the "Brylie Wilson" artifact in claude.ai (Portfolio Map Final). It is the real site running on the final content. Use the **Review** button (bottom centre) for keep / replace, stars and a note per work; ratings save for the next session.
- **Content:** 40 works at three levels. 3 projects (L), 5 Extras (M), 32 smaller works (S). Names, ordered images with alt text, facts, tools, materials, tags and copy for every one. Summary with open questions: `docs/CONTENT.md` in the repo.
- **Levels:** L big image tiles, rich hover, card, panel, full page. M image tiles, card, panel. S small thumbnails; the words carry them (hover shows context, team, tools, materials, tags; click shows an image strip, one line, facts and an "About this piece" disclosure).
